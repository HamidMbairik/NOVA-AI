# NOVA AI — AI SaaS

**Brand personality:** Futuristic, intelligent, technical, premium.

| Token | HEX | RGB |
|---|---|---|
| Primary | `#7C3AED` | `rgb(124, 58, 237)` |
| Secondary | `#4F46E5` | `rgb(79, 70, 229)` |

## Gradient

```
#7C3AED → #22D3EE
rgb(124, 58, 237) → rgb(34, 211, 238)
```

## Usage Rules

- Dark interface with purple as the primary brand color and cyan for secondary highlights.
- Gradients should be subtle and used mainly for hero elements, buttons and visual effects.
- **60%** Background/neutral · **30%** Primary/Secondary · **10%** Accent.
